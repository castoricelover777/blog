# 个人知识库（极简版）

一个用 **HTML5 + 原生 CSS + 原生 JavaScript** 写的个人知识库，记录所有学科的学习笔记。
只有 **marked.js** 一个外部库（用来把 Markdown 渲染成 HTML），没有框架、没有数据库、没有后端。

- **代码量**：`js/app.js` **代码 132 行**（注释不算行），加上详细中文注释后文件共 366 行；
  样式写在 `index.html` 的 `<style>` 里（HTML 不计入）；
- **语法**：只用 `for` 循环、`if-else`、`function`、`let`，以及 `数组.push / splice / findIndex`，
  没有箭头函数、模板字符串、解构、`const`、`map/filter/forEach`；
- **交互**：新增用连续 `prompt()` 问答，编辑用 `prompt()`，删除用 `confirm()`，没有弹窗和表单；
- **数据**：`data/notes.json` 文件 + 浏览器 `localStorage` 双保险。

## 二、怎么打开

**✅ 双击 `启动知识库.bat`** —— 它会启动一个只监听本机的小服务器，并自动打开浏览器
（地址形如 `http://127.0.0.1:8080/`）。关掉那个黑色窗口就是停止服务器。

**为什么不能直接双击 `index.html`？**
那样地址栏是 `file://…`，浏览器出于安全策略不允许 JavaScript 读取本地文件，
所以第一次打开会读不到 `data/notes.json`（页面会给你一句提示）。
用 bat 打开就没这个问题。这个限制和代码无关，是浏览器的同源策略。

## 三、四个按钮怎么用

| 按钮 | 位置 | 做什么 |
| --- | --- | --- |
| **＋ 新增** | 右上角 | 连着弹 4 个输入框：日期 → 标题 → 分类 → 正文，依次填完就新增一条 |
| **编辑** | 正文顶部 | 弹 2 个输入框，先改标题、再改正文 |
| **删除** | 正文顶部 | 弹一个"确定删除吗？"，确认后删掉 |
| **⬇ 下载数据** | 右上角 | 把当前全部记录导出成 `notes.json` 文件 |

- 新增时可以写"分类"里的任意内容（Java / 数据结构 / 算法 / 高数 都行）；日期默认是今天；
- 正文是 Markdown：`# 标题`、`**粗体**`、表格、列表、```` ```java ```` 代码块都能渲染；
- 点左边列表的任意一条，右边就显示它的内容（列表按日期从新到旧排列）。

## 四、⚠️ 数据到底存在哪里（这段最重要）

数据同时存在于两个地方，规则很简单：

```text
打开页面时：
    localStorage 里有数据？ ── 有 ──> 直接用缓存（所以刷新不丢）
                            └─ 没有 ─> 去读 data/notes.json，然后存进缓存

每次增/删/改：
    localStorage 立刻更新（磁盘文件不会被动，程序从不主动写文件）
```

由此带来三条**你一定要知道**的结论：

1. **刷新、关掉再打开，改动都不会丢**——因为缓存在浏览器里。
2. **想让磁盘文件也更新**，必须自己点【⬇ 下载数据】，把下载到的 `notes.json`
   复制到 `data/` 目录覆盖原文件。这一步是"导出备份"，也是"换电脑带走"的唯一方式。
3. **想用文件里的内容覆盖浏览器里的**（例如从 `.bak` 恢复），要先把缓存清掉：
   按 `F12` 打开控制台，输入下面这行再回车，然后刷新页面：

   ```js
   localStorage.removeItem('notes')
   ```

另外注意：`http://127.0.0.1:8080` 打开和 `file://` 双击打开，浏览器把它们当成两个不同的地址，
**各自的 localStorage 是分开的**。所以建议固定用 `启动知识库.bat` 打开，别混着来。

## 五、`data/notes.json` 的格式

就是一个数组，每条记录 5 个字段：

```json
[
  {
    "id": 1783612800000,
    "date": "2026-07-10",
    "title": "Java 基础：变量、数据类型与自动拆装箱",
    "category": "Java 基础",
    "content": "# Java 基础……\n\n正文用 Markdown 写\n"
  }
]
```

| 字段 | 说明 |
| --- | --- |
| `id` | `Date.now()` 生成的时间戳，唯一编号，不用管 |
| `date` | `2026-07-10` 这种格式，用作排序 |
| `title` | 标题 |
| `category` | 分类 |
| `content` | Markdown 正文。JSON 里换行写成 `\n` |

> 建议日常都在网页里编辑。手改 JSON 容易漏逗号、漏引号，而且正文换行要写成 `\n`，很麻烦。

## 六、代码导读（按这个顺序读）

> 三个源文件都写了很详细的中文注释：`js/app.js` 代码 132 行 / 注释 177 行，
> `index.html`（含 CSS）223 行，`tools/server.ps1` 代码 279 行 / 注释 137 行。
> `app.js` 开头还有一大段"名词解释"，讲清了 localStorage、JSON、fetch、DOM 分别是什么。

| 顺序 | 函数 | 干什么 |
| --- | --- | --- |
| 1 | `start()` | 入口：先看缓存，没有就读文件 |
| 2 | `showList()` | 刷新左边列表，用 `for` 循环拼 `<li onclick="showNote(下标)">` |
| 3 | `showNote(index)` | 右边显示：顶部按钮 + 标题 + `marked.parse()` 渲染正文 |
| 4 | `addNote()` | 4 个 `prompt()` → `notes.push()` → `sortNotes()` → 存缓存 → 刷新 |
| 5 | `editNote()` | 2 个 `prompt()` → 直接改数组里那个对象的字段 |
| 6 | `deleteNote()` | `confirm()` → `notes.splice(下标, 1)` |
| 7 | `downloadData()` | `JSON.stringify` → `Blob` → 造一个 `<a download>` 点击 |
| 8 | `saveCache()` | `localStorage.setItem('notes', JSON.stringify(notes))` |
| 9 | `sortNotes()` / `escapeHtml()` / `today()` | 排序、转义、取今天日期 |

几个容易踩的点，注释里都写了：

- `escapeHtml()`：把标题里的 `<` `>` `&` 换掉，否则一个尖括号就能把页面结构弄乱；
- 新增之后要 `findIndex` 重新找它的下标，因为排序完位置变了；
- 点"取消"时 `prompt()` 返回 `null`，所以每个输入都要判断 `== null`。

`app.js` 最末尾还有一段"调试小技巧"注释：按 F12 后可以用 `notes`、`notes.length`、
`localStorage.getItem('notes')` 这些命令直接查看数据。

> ⚠️ **不要改 `tools/server.ps1` 的保存编码**：它里面有中文注释，
> 必须存成 **UTF-8 带 BOM**。Windows PowerShell 5.1 读没有 BOM 的 `.ps1` 会按 GBK 解码，
> 中文会乱码、严重时直接报语法错误。用 VSCode 改的话，右下角编码要选 `UTF-8 with BOM`。

## 七、常见问题

**Q：右上角点【新增】没反应？**
A：`prompt()` 被浏览器拦了？检查是不是在无痕窗口或禁用了弹窗。正常窗口不会有问题。

**Q：能自动保存到 `data/notes.json` 吗？**
A：现在的设计是手动点【⬇ 下载数据】再覆盖文件（这是你要求的极简方案）。
   如果想"点一下就写回文件"，需要服务器提供一个保存接口——现在用的 `tools/server.ps1`
   里已经保留了一个 `POST /api/save` 接口（当初的完整版用它写文件），
   想启用的话我可以在 `app.js` 里加上调用它的几行代码。

**Q：代码块没有颜色？**
A：为了遵守"只允许 marked.js 一个第三方库"，去掉了代码高亮库（highlight.js），
   代码块现在只有背景和边框。想要高亮，就得再引入一个库（highlight.js，本地放一份即可），
   需要的话告诉我，我加上——这会打破"只有一个第三方库"的约定，所以先不动它。

**Q：能不能换配色？**
A：`index.html` 里 `<style>` 的第一段：`background: #0d1117`（底色）、`color: #e6edf3`（文字色），
   `#58a6ff` 是那个蓝色的分类标签。

**Q：能换台电脑用吗？**
A：能。先在原电脑点【下载数据】拿到 `notes.json`（覆盖 `data/` 里的），
   再把整个 `JavaBlog` 文件夹拷到新电脑（Windows + PowerShell 即可），双击 `启动知识库.bat`。

**Q：手机上能看吗？**
A：窄屏时列表会自动跑到上面、内容在下面，可以看也可以编辑（`prompt` 弹窗手机上会正常显示）。

**Q：之前的旧版本还能找回吗？**
A：已经删掉了。不过**内容一点没丢**：删之前我逐篇核对过，旧 `logs/*.md` 那三篇原稿的正文
   一字不差地保存在 `data/notes.json` 里（就是你现在看到的那三条）。
   丢掉的只是旧版代码（一个是"日志博客"，一个是"完整版知识库"），以后需要可以重写。
