# 前后端数据沟通全链路 · 思维导图

**在线查看：<https://castoricelover777.github.io/blog/mindmap/>**

以「用户注册」为案例，把一次请求从浏览器点击到数据库落库的全过程，
拆成 **353 个节点**的思维导图。

## 文件说明

| 文件 | 说明 |
|---|---|
| `index.html` | 双向思维导图（根居中、阶段左右分列），单文件、无外部依赖 |
| `chain.html` | 同一份内容的横向长链图，按六段式时序排列 |
| `preview.png` | 导图海报，3192 × 1995 |
| `chain-preview.png` | 长链图海报，3256 × 981 |
| `marks.json` | 内置的 228 条学习标记，可在页面「导入标记」直接使用 |
| `source.md` | 原始 Markdown 大纲，要改内容改这个 |

## 内容规模

- **353 个节点**：1 根 + 11 个一级分支 + 60 个环节 + 281 个细节
- 11 个分支 = 阶段〇（全景速览）+ 阶段一~六（六段式时序）+ 附录 A~D
- 主线：前端触发 → 网络传输 → 后端接收 → 业务处理 → 数据库持久化 → 响应返回

## 怎么用

点开即用，不联网、不用装任何东西。

| 操作 | 效果 |
|---|---|
| 点击节点 | 展开 / 折叠子节点（圆里的数字 = 子节点数） |
| 滚轮 | 以鼠标位置为中心缩放 |
| 拖拽空白处 | 平移画布 |
| 节点右侧小圆 | 标记掌握程度：红 = 不会，黄 = 仅了解，绿 = 理解 |

工具条：`全部展开` `只看阶段` `展开到环节` `适应窗口` `载入作者标记` `导出标记` `导入标记` `清空标记`

地址栏参数可直接指定初始视图：

- `?view=collapse` 只看 11 个阶段
- `?view=items` 展开到 60 个环节（默认）
- `?view=all` 353 个节点全展开

长链图另有 `?detail=1`（展开所有细节）和 `?clean=1`（净图模式，适合截图）。

## 关于内置标记

页面里带着作者的 **228 条学习标记**（不会 50 / 仅了解 97 / 理解 81）：

- **首次打开自动载入**，直接能看到每个知识点的掌握程度
- 标记存在浏览器 localStorage，刷新、关掉重开都不丢；换设备不同步
- 点「清空标记」可以从头开始标，之后不会再自动回填
- 想恢复作者的标记，点「载入作者标记」
- 想同步到别的设备：`导出标记` 下载 json，在另一台机器 `导入标记`

## 自己改

`source.md` 是唯一的内容源：`#` 根 → `##` 阶段 → `###` 环节 → `####` 细节，
标题下方的正文会自动并入标题（标题含「：」用 `——` 连接，否则用 `：`）。

`index.html` / `chain.html` 是**单文件、零依赖**的，也可以直接改里面的
`const DATA = {...}`，不用任何构建工具。
